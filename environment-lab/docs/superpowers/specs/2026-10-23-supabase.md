# Supabase test foundation

Implement the approved Supabase test architecture without changing the existing private audience or ChatGPT sign-in. The trusted hosting identity enters a server-only bridge. No Supabase administrator credentials reach the browser or the model. Postgres is authoritative for new connected tasks; legacy R2 tasks remain readable and continue in R2, without dual writes or silent migration.

Store projects, membership mappings, versioned runs/checkpoints, events, delegations, external effects, artifact metadata, connection grants and audit findings. Every application table uses RLS; authenticated users can read only projects explicitly mapped to their Supabase Auth ID. Creating such mappings requires an operator. Browser clients cannot write runtime state directly. Preserve the runtime's revision-specific receipt gates, 100-second lease, stop flag and unknown-effect reconciliation.

Provision three private Storage buckets: context-files, artifacts, audit-reports. Immutable objects are scoped to an owned run, content-addressed and verified by SHA-256. A failed upload cannot produce a confirmed metadata receipt.

Use pgmq for durable work, with a one-minute Cron dispatcher through pg_net and Vault-held authentication. One Edge Function processes one bounded runtime step per invocation; no 15-minute in-memory loop. Claim and completion tokens must fence stale queue workers. Failed deliveries retry with bounded attempts; expired execution leases pause for review, and unknown external effects never replay. Preserve polling; do not add Realtime or pgvector yet.

The Edge processor may execute real built-in CPU work without a model as an explicit infrastructure diagnostic. General reasoning still requires a real model credential and model selection; model configuration is server-only and must not be inferred from a successful CPU diagnostic. MCP grants remain operator-owned. Do not claim independent audits or deployed-target acceptance without actual receipts.

Verify real hosted ownership isolation, CAS races, private files, stale-job fencing, scheduled processing without a browser and duplicate delivery. Measure actual API durations and outputs. Keep credentials, private Site identity and user records out of the public source export.
